# 羊的资料库

面向大一、大二同学的学习资料与 AI 实用教程导航站。

- 网站只提供内容说明与入口，具体资料统一维护在飞书文档中。
- 基础资料公开分享，部分进阶 AI 教程需要联系获取。
- 站点基于 Jekyll 构建，通过 GitHub Pages 发布。

## 本地预览

```bash
bundle install
bundle exec jekyll serve
```

浏览器打开 `http://127.0.0.1:4000/`。

## 更新资料入口

资料名称、说明、状态和飞书链接统一维护在 `_data/resources.yml`。填入链接后重新构建即可。

## 模板来源

页面基于 [academic-homepage](https://github.com/luost26/academic-homepage) 改造。
